# Publication audit scope

The manuscript and reproducibility payload omit the depositor's personal name, affiliation, email, ORCID, local home-directory paths, correspondence and submission identifiers. The PDF has fourteen pages, no author field, no attachments, no annotations, no forms and no JavaScript. Its extracted text and metadata were checked, and all fourteen rendered pages were visually inspected.

The TeX, Python, saved certificates, instructions, verifier, public key, filenames and final archive members were checked. The public payload contains neither a private key nor a password, recovery code, private authorship record, browser session or inherited Git history. Scholarly citations and the AI contribution statement are retained.

This is content anonymity, not author unlinkability. The public hosting account and commit metadata can identify the depositor. The dedicated release key has a neutral user ID and does not independently authenticate a human author's identity.

The manuscript PDF, TeX, mathematical programs and finite input/result files are unchanged from the reviewed research version. Release documentation and verification/provenance files are additions. The reproducibility archive is rebuilt twice with normalized ZIP metadata and replayed from fresh extractions, including optimized Python. Public-byte verification is recorded separately after upload.
